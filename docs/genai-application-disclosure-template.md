## Instruções de preenchimento

1. **Modelo** — nome e versão exatos (ex.: `Claude Opus 5`). Se houve mudança
   de modelo a meio da preparação, registar cada um separadamente.
2. **Secção afetada** — identificar com precisão (ex.: "Resumo do projeto",
   "Descrição técnica — normordis-pdf", "Orçamento e justificação").
3. **Prompt** — o texto exato, não uma paráfrase. Iterações sucessivas do mesmo
   prompt registam-se como linhas separadas.
4. **Output não editado** — obrigatório. Que o texto final difira do output é
   esperado e aceite: o objetivo é tornar visível a diferença entre o que o
   modelo produziu e o que ficou depois da verificação humana, não desencorajar
   a edição.
5. **Avaliação interativa** — se houver entrevista ou troca de mensagens com a
   entidade financiadora e usares IA para preparar respostas, essas interações
   também entram aqui.
6. **Pesquisa e verificação de factos** não precisam de constar: a obrigação
   cobre redação, tradução e sumarização, não pesquisa.

## Nota sobre o uso de Claude Code

Claude Code usado para **desenvolver o projeto** entra em
[ai-provenance.md](ai-provenance.md). Claude Code usado para **redigir ou rever
texto da candidatura** entra neste log. A mesma ferramenta, dois registos,
consoante o que produziu.

Na dúvida, registar em ambos. O custo de registar a mais é nulo; o de registar
a menos, não.
