# Normative references register

This register separates normative dependencies from informative background.
Before every stable release, editors must verify status, amendments and
withdrawals against the issuing organisation.

## Normative

- IETF RFC 8259, *The JavaScript Object Notation (JSON) Data Interchange
  Format*.
- IETF RFC 8785, *JSON Canonicalization Scheme (JCS)*.
- IETF RFC 4648, *The Base16, Base32, and Base64 Data Encodings*.
- IETF RFC 5652, *Cryptographic Message Syntax (CMS)*.
- IETF RFC 3161 and RFC 5816, time-stamp protocol and ESSCertIDv2 update.
- IETF RFC 5280, X.509 certificate and CRL profile.
- IETF RFC 6960, OCSP.
- JSON Schema Core and Validation, Draft 2020-12.
- ETSI EN 319 122-1, CAdES baseline signatures.
- ETSI EN 319 102-1, creation and validation procedures for AdES signatures.
- ETSI EN 319 422, time-stamping protocol and token profiles.
- ETSI EN 319 142-1, PAdES baseline signatures, only for the optional PDF
  output profile.

## Informative or profile-dependent

- ISO 15489-1, records management concepts and principles.
- ISO 23081 series, metadata for records.
- ISO 14721, OAIS reference model.
- ISO 32000-2, PDF 2.0.
- ISO 19005 series, PDF/A.
- ISO 14289 series, PDF/UA.
- ISO/IEC 26300, OpenDocument Format.

Legal instruments and national archival instruments are jurisdictional inputs,
not technical serialization standards. Their applicability must be reviewed by
the adopting organisation.
