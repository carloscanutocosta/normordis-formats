# Registo de referências normativas

Este registo separa dependências normativas de referências informativas. A
edição aplicável deve ser fixada antes de uma versão candidata. O estado,
emendas, erratas e substituições são confirmados na fonte oficial antes de cada
publicação estável.

## Referências normativas comuns

| Organismo | Identificador | Título | Aplicação |
|---|---|---|---|
| IETF | RFC 2119 e RFC 8174 (BCP 14) | *Key words for use in RFCs to Indicate Requirement Levels*; atualização sobre maiúsculas e minúsculas | interpretação da linguagem normativa |
| IETF | RFC 8259 | *The JavaScript Object Notation (JSON) Data Interchange Format* | sintaxe e modelo JSON |
| IETF | RFC 8785 | *JSON Canonicalization Scheme (JCS)* | bytes JSON canónicos |
| IETF | RFC 4648 | *The Base16, Base32, and Base64 Data Encodings* | codificações base |
| IETF | RFC 9562 | *Universally Unique IDentifiers (UUIDs)* | UUID, incluindo UUIDv4; substitui RFC 4122 |
| IETF | RFC 5652 | *Cryptographic Message Syntax (CMS)* | contentor criptográfico |
| IETF | RFC 3161 e RFC 5816 | *Time-Stamp Protocol* e atualização ESSCertIDv2 | tokens de tempo |
| IETF | RFC 5280 | perfil de certificados X.509 e CRL | validação de certificados |
| IETF | RFC 6960 | *Online Certificate Status Protocol — OCSP* | estado de revogação |
| JSON Schema | Draft 2020-12, Core e Validation | *JSON Schema* | validação estrutural |
| ETSI | EN 319 122-1 V1.3.1 (2023-06) | *CAdES digital signatures — Part 1: Building blocks and CAdES baseline signatures* | assinaturas CAdES |
| ETSI | EN 319 102-1 V1.4.1 (2024-06) | procedimentos de criação e validação de AdES | validação de assinaturas |
| ETSI | EN 319 422 V1.1.1 (2016-03) | protocolo e perfis de tokens de tempo | serviço de timestamp |
| ETSI | EN 319 142-1 V1.2.1 (2024-01) | assinaturas PAdES baseline | perfil opcional de saída PDF |

Estas edições são a base editorial atual. Antes de uma versão candidata, a
revisão de referências DEVE confirmar se continuam vigentes e registar qualquer
decisão de manter uma edição anterior por interoperabilidade.

## Referências informativas ou dependentes de perfil

- ISO 15489-1, *Information and documentation — Records management — Part 1:
  Concepts and principles*.
- série ISO 23081, metadados para documentos de arquivo.
- ISO 14721, *Space data and information transfer systems — Open archival
  information system (OAIS) — Reference model*.
- ISO 32000-2, *Document management — Portable document format — Part 2: PDF
  2.0*.
- série ISO 19005, PDF/A.
- série ISO 14289, PDF/UA.
- ISO/IEC 26300, OpenDocument Format.

Instrumentos jurídicos e instrumentos arquivísticos nacionais são entradas de
perfil jurisdicional, não normas de serialização. A sua aplicabilidade deve ser
avaliada pela entidade adotante e por especialistas competentes.
